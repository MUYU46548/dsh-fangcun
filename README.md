# dsh-fangcun —— 方寸 × DSH 插件

**本项目使用AI辅助开发**。

把[方寸（tegula）](https://github.com/MUYU46548/fangcun) 高效接入DSH，提升DSH调用方寸的主动性和准确性。

本项目是方寸的**附属项目**，需要先安装方寸才能正常使用。本项目为[DSH](https://github.com/deepseek-ai/deepseek-harness)插件，无法单独使用，需要安装到DSH中使用。

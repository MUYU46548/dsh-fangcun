# dsh-fangcun —— 方寸 × DSH 插件

**本项目使用AI辅助开发**。

把[方寸（tegula）](https://github.com/MUYU46548/fangcun) 高效接入DSH，提升DSH调用方寸的主动性和准确性。

本项目是方寸的**附属项目**，需要先安装方寸才能正常使用。本项目为[DSH](https://github.com/deepseek-ai/deepseek-harness)插件，无法单独使用，需要安装到DSH中使用。随着DSH Windows 桌面版的版本变化，本插件可能不再适用。作者会尽快跟进新版DSH，但不为可用性提供担保。

如果喜欢本项目，欢迎到[爱发电](https://afdian.com/a/muyu46548B?utm_source=copylink&utm_medium=link)支持作者！

## 安装

强烈推进将安装和更新维护交给Agent，自动处理安装、备份和升级检查。
